The `-lyrics_stat` parameter applies a static color scheme to Spotify's lyrics view, locking it to a chosen palette and overriding Spotify's dynamic color algorithm that normally shifts colors based on the currently playing track's artwork. This is useful if you prefer a consistent, predictable look in the lyrics panel regardless of what you're listening to.

## Usage

Pass `-lyrics_stat` followed by one of the 27 valid theme names:

```powershell
iex "& { $(iwr -useb 'https://raw.githubusercontent.com/SpotX-Official/SpotX/refs/heads/main/run.ps1') } -new_theme -lyrics_stat spotify"
```

You can combine `-lyrics_stat` with any other SpotX parameter. The `-new_theme` flag is not required for lyrics theming, but it is recommended for the best visual consistency.

<Note>
  Using `default` as the value explicitly restores Spotify's own dynamic color algorithm — the lyrics view will shift colors based on each track's cover art, which is also the behavior when `-lyrics_stat` is omitted entirely.
</Note>

## Disabling Lyrics Entirely

If you prefer not to use Spotify's native lyrics feature at all, pass `-lyrics_block` instead:

```powershell
iex "& { $(iwr -useb 'https://raw.githubusercontent.com/SpotX-Official/SpotX/refs/heads/main/run.ps1') } -lyrics_block"
```

This removes the lyrics panel from the Spotify UI completely. It cannot be combined with `-lyrics_stat` — use one or the other.

## Tips

<Tip>
  The `spotify` and `spotify#2` themes are the closest match to Spotify's official green brand color (`#1DB954`). They are a good choice if you want lyrics theming that feels native and on-brand rather than a custom accent.
</Tip>

<Tip>
  Theme names are tab-completable directly in PowerShell. If you run `run.ps1` locally rather than via `iex`, type `-lyrics_stat ` and press <kbd>Tab</kbd> to cycle through all 27 options.
</Tip>
