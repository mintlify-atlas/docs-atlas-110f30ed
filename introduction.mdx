SpotX is an open-source PowerShell-based patcher for the **Spotify desktop client on Windows**. With a single command, it strips all banner, video, and audio advertisements from your Spotify session, silences analytics and telemetry calls, unlocks a range of experimental UI features, and gives you fine-grained control over updates and podcast visibility — all without requiring a paid subscription or any third-party application framework.

## Key Features

- **Blocks all banner, video, and audio ads** inside the Spotify desktop client
- **Hides podcasts, episodes, and audiobooks** from the homepage (optional, prompted at install time)
- **Blocks Spotify automatic updates** so a patched version stays intact (optional)
- **Disables analytics and telemetry** — prevents usage data from being sent to Spotify
- **Activates native experimental features** shipped inside the client but not yet publicly enabled
- **New-theme support** — enables the updated left and right sidebars and refreshed cover artwork layout
- **Lyrics theme customization** — choose from over 25 static color themes (e.g. `spotify`, `blue`, `discord`, `purple`) for the lyrics view
- **Microsoft Defender exclusion management** — optionally registers SpotX paths as exclusions to prevent false-positive detections
- **Multilingual installer** — supports 34 languages including English, Spanish, French, German, Japanese, Chinese, Russian, and more
- **No admin rights required** by default — runs fully in user space (Defender exclusion prompts may request elevation)
