SpotX is an open-source patcher for the Spotify desktop client on Windows. It blocks banner, video, and audio ads, disables analytics, and applies a range of optional UI tweaks — all with a single PowerShell command or a click of a `.bat` file. No account changes, no third-party servers required.

## What SpotX Does

SpotX patches the Spotify client's internal JavaScript and binary files at install time. The patch is applied locally on your machine and survives Spotify restarts — until Spotify updates itself, at which point you simply re-run the patcher.

## Quick Install

The fastest way to install SpotX is to run this command in PowerShell:

```powershell
iex "& { $(iwr -useb 'https://raw.githubusercontent.com/SpotX-Official/SpotX/refs/heads/main/run.ps1') } -new_theme"
```

<Note>
  Spotify must be the **official desktop version** — not the Microsoft Store edition. PowerShell 5.1 or above is required.
</Note>

## Installation Types

<Steps>
  <Step title="Choose your theme">
    SpotX supports the current Spotify UI (new theme) and the legacy UI (old theme, locked to Spotify 1.2.13).
  </Step>
  <Step title="Pick your install method">
    Run the PowerShell command directly, download and run a `.bat` launcher, or compose a fully automated command with CLI flags.
  </Step>
  <Step title="Answer the prompts">
    The installer asks whether to hide podcasts and whether to block Spotify updates. Both can be pre-answered with flags for silent installs.
  </Step>
  <Step title="Done">
    Spotify restarts patched. Re-run SpotX after any Spotify update to reapply the patch.
  </Step>
</Steps>
